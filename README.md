## Engineering Philosophy

- **Architecture first:** Understand the system before implementing it.
- **Know the dependencies:** Understand how components rely on one another.
- **Test assumptions:** Verify expected behaviour through practical testing.
- **Troubleshoot by layer:** Investigate problems systematically.
- **Document results:** Record implementations, findings and limitations honestly.
